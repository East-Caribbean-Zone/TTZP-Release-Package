# Piarco FIR (TTZP) – EuroScope package

Download page for the Piarco FIR (TTZP) EuroScope sector package. EuroScope can install and update it by itself.

## Installing

1. In EuroScope, open **Open SCT → Download Sector Files…**.
2. Fill in the fields below the provider list, then click **New**:
   - **Name:** `TTZP Piarco FIR - VATCAR`
   - **URL:** `https://github.com/East-Caribbean-Zone/TTZP-Release-Package/releases/latest/download/TTZP_Sector_Provider.txt`
   - **Filename:** `TTZP_Sector_Provider.txt` in the folder where you want the package, e.g. `C:\EuroScope\TTZP\TTZP_Sector_Provider.txt`. The package is unpacked into that folder.
3. Tick **A** on the new provider and click **Download**.
4. Under **Provided Sector Files**, tick **A** on the package and click **Download**.

EuroScope then checks for updates at start-up and offers to switch your profiles to each new version. Each update overwrites the package files in that folder, so keep personal changes in your own copies.

You can also download the package by hand from [Releases](https://github.com/East-Caribbean-Zone/TTZP-Release-Package/releases/latest).
